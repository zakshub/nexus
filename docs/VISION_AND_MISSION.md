# Vision and Mission

## Vision

A personal computing environment that remembers how it is configured, understands its boundaries, and helps its owner operate it safely.

## Mission

NEXUS captures and organizes verified technical knowledge about the owner's devices and workflows, then uses that context to provide accurate retrieval, troubleshooting, and guided operations.

## Product promise

NEXUS should reduce repeated setup work and prevent confusion about where a command belongs, what it changes, and whether it has been verified.

## Principles

### Memory before autonomy
Build useful, searchable memory before adding execution.

### Context before command
Know the device, operating system, shell, and execution environment before presenting instructions.

### Explain before action
Show the purpose, expected result, and risk of an operation in language the user understands.

### Approval before change
State changing operations require explicit approval for the specific action.

### Evidence before confidence
Label facts as verified, user reported, inferred, or unverified.

### Owner control
The owner controls stored data, device connections, permissions, exports, and deletion.

## Long term direction

NEXUS may evolve from a personal technical notebook into a cross device assistant. That direction depends on proving the personal use case and validating safe integration boundaries first.
